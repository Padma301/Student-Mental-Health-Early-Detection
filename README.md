# AI-Based Early Detection of Student Mental Health Issues Using Academic & Behavioral Data

## Project Overview
This project aims to develop a machine-learning-based early-warning support system using student academic and behavioral indicators.

The system identifies patterns that may indicate a need for additional student support. It is not a medical diagnosis tool.

## Objectives
- Analyze academic and behavioral patterns.
- Apply machine learning techniques.
- Develop a web application using Flask.
- Display results through a dashboard.
- Support early human review.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Flask
- HTML, CSS, Bootstrap
- SQLite

## Project Modules
1. Dataset Preparation
2. Data Preprocessing
3. Machine Learning Model Training
4. Model Evaluation
5. Flask Backend
6. Database Integration
7. Dashboard Development

## Project Status
Initial development stage.

## Important Note
The initial dataset will contain synthetic data for software development and testing. Predictions are not clinical assessments or diagnoses.
